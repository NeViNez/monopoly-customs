# Monopoly — вечер с друзьями

Самостоятельное клиент-серверное приложение для игры через браузер. Интерфейс на русском: цветные группы объединяют достопримечательности восьми районов Новосибирска, транспортные объекты — четыре моста. Node.js + WebSocket, без базы данных, фронтенд без сборки и внешних CDN.

Оформление — по мотивам «Миллионер Elite» издательства Origami: белые клетки районов, синий центр, ночной город и название с золотой фактурой. Главная страница, лобби и игровые панели используют общую тему `public/elite.css`. Новые партии используют адаптацию Elite; сохранённые партии продолжаются на прежней раскладке и движке.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm start
```

Откройте http://localhost:3000. Для игры с другого компьютера в локальной сети используйте `http://IP-компьютера-с-сервером:3000`. Разрешите входящие подключения к этому порту в локальной сети, если их блокирует брандмауэр. Ссылка-приглашение использует адрес, по которому вы сами открыли игру: ссылка с `localhost` подходит только вашему компьютеру.

Создайте комнату, укажите никнейм и передайте друзьям ссылку или код. Никнеймы могут совпадать; пароль игрока не нужен. Создатель начинает партию, когда собралось 2–8 игроков. Первый игрок определяется серверными бросками кубиков с перебросом ничьей.

`npm run dev` перезапускает сервер при изменениях. `PORT` меняет порт, `HOST` — адрес прослушивания; по умолчанию `0.0.0.0:3000`.

## Возможности

- Комнаты, приглашения, лобби, чат, восстановление связи и включаемый серверный автопилот.
- 40 клеток: восемь районов по три участка, четыре моста, СГК / РЭС и десять специальных клеток. «Фортуна» заменяет казну на клетке 15.
- Золотое название, белые участки, чёрные подписи и номера, жёлтые границы. Залог показан светло-серой заливкой с читаемым текстом.
- Последовательные прыжки фишек через каждую клетку, счётчик шагов, карты событий с переворотом в центре поля и поддержка уменьшенного движения.
- 20 подтверждённых позиций «Фортуны»: коллективные разовые эффекты, отдельные длительные условия, отложенные события, открытая стопка и повторное чтение без повторного списания.
- Казино с исходными шестипозиционными барабанами, одной попыткой за посещение, отдельной кассой, серверным результатом и анимацией выплаты.
- Акции, дивиденды, круговые налоги, налоговая инспекция, льгота, случайные аукционы и четыре вида страховых полисов.
- 96 домов и 24 отеля; равномерная застройка до трёх домов, затем отель. Долг, залог, обмен, банкротство, победитель и реванш.

## Правила новой партии

Основа — [инструкция Elite](https://hobbygames.ru/download/rules/Pravila_millionaire_elite_compressed.pdf), подтверждённые фотографии компонентов и [паспорт НСК 0.8](https://chatgpt.com/space/page_714b538bbf58819195bf558083aae235). Начальный капитал — 2 000 фантов. Доход за Старт — 200 плюс 20% текущей стоимости акций. В банке 48 акций с начальным курсом 100; Биржа меняет курс на 1–6 пунктов по 10 фантов. В интерфейсе показываются текущая аренда и налог владельца, рассчитанные сервером.

Цены участков и базовая таблица аренды сохранены из предыдущей НСК-версии; это адаптация, а не полная копия экономики оригинального поля. Базовые налоги перенесены по тематическому соответствию районов: Центральный — СМИ (15), Заельцовский — развлечения (3), Калининский — добыча (30), Дзержинский — связь (5), Ленинский — пищевая промышленность (100), Кировский — лёгкая (10), Октябрьский — тяжёлая (25), Железнодорожный — транспорт (20). Налоговые множители Elite: пустая монополия ×2, один/два/три дома ×4/×6/×9, отель ×15; мосты — 50/100/200/500 за каждый при владении 1/2/3/4 мостами. Базовый налог инфраструктуры НСК — 10 за объект. Залог отменяет аренду, но не круговой налог. Выкуп стоит 60% исходной цены.

Уточнения цифровой версии, согласованные 31 октября: при равенстве показателей выбирается первый участник в текущем порядке хода; половины округляются вниз; новая «Фортуна» отменяет несработавшее условие предыдущей; третий участок бесплатно выдаётся только из банка. Временные полисы возвращаются на Старте. Бесплатный красный полис C1R2 переходит к игроку с минимумом наличных; использованный бесплатный полис повторно тому же игроку в рамках этой карты не выдаётся. Особая продажа C4R1 проводится по 300, после неё сохраняется обычный текущий курс. Неподтверждённые десять карт «Фортуны» не придуманы: после исчерпания двадцати позиций последняя остаётся действующей. «Шанс» пока использует прежнюю колоду из 16 индивидуальных инструкций, перенаправленных на объекты нового поля; посреднических сделок на Бирже нет.

Казино: ставка 50 фантов, касса начинается с 200, одна добровольная попытка за посещение. Ровно два одинаковых символа в любых позициях дают ×2/×3/×5 для вишен/колокольчиков/слив; две семёрки — всю кассу. Тройки дают ×10/×20/×30/×50 и имеют приоритет над парой. Обычные выплаты идут из банка, ставка отдельно не возвращается и остаётся в кассе. Джекпот обнуляет кассу. C2R4 даёт два броска на каждый барабан; сервер выбирает лучшую из восьми комбинаций. Броски казино не меняют фишку и счётчик дублей.

Все действия проходят через общий серверный обработчик. Новое действие хода недоступно, пока владелец открытой карты не нажал «Продолжить». Чтение действующей «Фортуны» не отправляет игровой команды. Секретный порядок колод не передаётся клиентам. Сохранённые партии без `rules: "elite"` сохраняют прежние индексы, собственность и механику Monopoly; новая версия применяется при создании следующей партии.

## Данные и возвращение в игру

Комнаты хранятся в `data/rooms.json`; запись через временный файл и переименование. Каталог `data` не публикуется HTTP-сервером и исключён из Git. Для резервной копии сохраните каталог `data` при остановленном сервере.

После закрытия вкладки откройте главную страницу и нажмите «Продолжить» в разделе своих игр. При очистке данных браузера или смене устройства восстановить место по одному никнейму нельзя.

Идентичность игрока определяется случайным секретом браузера, а не никнеймом. Не передавайте сохранённые данные сессии другим людям. Две вкладки с одной сессией не управляют игроком одновременно: новое подключение заменяет старое. Для теста двух игроков используйте отдельные новые вкладки.

Это сервер для небольшой компании: один процесс, сохранение в JSON. Несколько экземпляров за балансировщиком с общим файлом данных не поддерживаются. Комнаты автоматически не удаляются.

## Production: nginx Basic Auth

В игре нет аккаунтов или паролей. Доступ ко всему приложению ограничивается **на nginx**, включая HTML, JavaScript и WebSocket. Пример: `deploy/nginx.conf`.

1. На сервере выполните `docker compose up -d --build`. Контейнер доступен только на `127.0.0.1:3000`, данные — в постоянном Docker volume.
2. Укажите свой домен и пути к уже выданному TLS-сертификату в конфигурации nginx. Установите nginx и `apache2-utils` средствами вашей ОС.
3. Создайте файл паролей командой `sudo htpasswd -c /etc/nginx/monopoly.htpasswd friends`. Пароль вводится интерактивно. Для добавления следующих пользователей **не используйте `-c`**, чтобы не перезаписать файл.
4. Убедитесь, что nginx может читать этот файл. Подключите конфигурацию, выполните `sudo nginx -t`, затем `sudo systemctl reload nginx`.
5. Задайте `PUBLIC_ORIGIN=https://ваш-домен` для сервера при необходимости явной проверки Origin. По умолчанию WebSocket разрешает Origin с тем же Host.

Без Docker запускайте Node за nginx с `HOST=127.0.0.1`. Не открывайте порт Node наружу в production, иначе nginx-аутентификацию можно обойти. TLS-конфигурация и домен требуют настройки на вашем сервере; приложение не развёрнуто в Интернете автоматически.

## Проверка

```sh
npm test
```

Тесты используют встроенный Node test runner: сценарии правил и настоящие WebSocket-клиенты. Интеграционная проверка создаёт временное хранилище, проверяет двух игроков с одинаковыми никами, запрет чужого хода, восстановление подключения и перезапуск сервера с сохранённой партией. CI запускает проверки на Node 22.

## Файлы

- `lib/board.js` — поле, цены, аренда, колоды.
- `lib/game.js` — правила и переходы состояния; не зависит от HTTP.
- `server.js` — HTTP, комнаты, сессии, WebSocket, хранение.
- `public/` — клиент и оформление.
- `tests/` — сценарии правил и сетевые проверки.
- `deploy/nginx.conf`, `Dockerfile`, `compose.yaml` — запуск на сервере.
- `ASSETS.md` — найденные оригинальные материалы, ссылки и условия использования.

Оформление поля создано средствами HTML/CSS; фишки отображаются системными emoji. Внешние изображения Hasbro не загружаются и не включены в репозиторий. Это личный неофициальный проект; он не связан с Hasbro.

### Docker с nginx на порту 34291

Создайте на сервере `deploy/monopoly.htpasswd` командой `htpasswd -c deploy/monopoly.htpasswd testMonopoly` и введите пароль интерактивно. Файл исключён из Git. Запуск: `docker compose -f compose.production.yaml up -d --build`. nginx публикуется на порту 34291 и проверяет Basic Auth для всех запросов, включая WebSocket; порт Node наружу не публикуется. Данные хранятся в Docker volume. Проброс TCP 34291 на роутере должен вести на порт 34291 сервера.

Этот вариант использует HTTP: Basic Auth не шифрует пароль. Для шифрования соединения настройте TLS на nginx или используйте защищённый VPN.
